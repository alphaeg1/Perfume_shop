دليل تشغيل السيستم

السيستم 3 حاجات: برنامج على اللابتوب (للحساب الرئيسي وكل الفروع)، موقع للعملاء (للموبايل)، وصفحة متابعة تفتحها من موبايلك زي الأبلكيشن.

1) جرّب السيستم دلوقتي (من غير أي إعداد)

  1. فك ضغط الملف، وادخل فولدر install، ودوس دبل كليك على Install.cmd.
  2. هيظهر على سطح المكتب أيقونة سيستم البرفيوم وهيفتح لوحده في نافذة لوحده زي أي برنامج.
  3. اختار تجربة السيستم وادخل بـ admin وكلمة السر 123456. لحساب فرع: maadi / 123456.

وضع التجربة على الجهاز ده بس. علشان الفروع تتربط ببعض على النت لازم الخطوة اللي جاية (مرة واحدة بس).

2) ربط الفروع ببعض على النت (Firebase — مرة واحدة)

  1. افتح console.firebase.google.com بحساب جوجل، ودوس Create a project، اكتب أي اسم، واقفل Google Analytics، وكمّل.
  2. من القايمة: Build ← Realtime Database ← Create database. اختار Belgium (europe-west1)، وبعدين Start in locked mode.
  3. في نفس الصفحة ادخل تبويب Rules، امسح اللي فيه، والصق كل محتوى الملف firebase/database.rules.json، ودوس Publish.
  4. من القايمة: Build ← Authentication ← Get started ← Email/Password، فعّل أول اختيار، ودوس Save.
  5. دوس على الترس جنب Project Overview ← Project settings ← تحت في Your apps دوس علامة </>، اكتب أي اسم، ودوس Register app. انسخ الكود اللي فيه firebaseConfig كله.
  6. افتح البرنامج على اللابتوب الرئيسي ← ربط بالسحابة ← الصق الكود ← اربط الجهاز ← اعمل الحساب الرئيسي.

لو الكود اللي نسخته مفيهوش databaseURL، خد رابط قاعدة البيانات من أول صفحة Realtime Database (بيبدأ بـ https وآخره firebasedatabase.app) وضيفه للكود.

3) أول حاجة تعملها في الحساب الرئيسي

  1. المنتجات والأسعار: في كل خانة (فرنساوي، خليجي، أزايز أشكال) ضيف الأحجام وسعر كل حجم، مثلاً 100 مللي و50 مللي و30 مللي. وارفع صورة لكل حجم لو عايزها تظهر على الموقع.
  2. الأوريجينال: ضيف الأحجام، وبعدين ضيف كل منتج أوريجينال عندك بالسعر بتاعه.
  3. الفروع والحسابات: ضيف الفروع، واعمل لكل موظف حساب في فرعه، وحدد كل فرع يشوف إيه.
  4. المخزون ← استلام بضاعة: اكتب عدد الأزايز اللي في كل فرع من كل حجم.

4) أجهزة الفروع

  1. على جهاز الفرع: نفس خطوة التثبيت (Install.cmd).
  2. في الحساب الرئيسي: الإعدادات ← كود ربط أجهزة الفروع ← نسخ الكود، وابعته للفرع.
  3. على جهاز الفرع: ربط بالسحابة ← الصق الكود ← سجّل دخول بحساب الموظف.

كل فرع على أي نت وفي أي مكان. أي بيعة بتظهر عندك في ثواني. ولو النت فصل عند فرع، الفرع بيبيع عادي، والبيانات بتترفع لوحدها أول ما النت يرجع.

5) الموقع وصفحة المتابعة على الموبايل

  1. في البرنامج: تبويب الموقع ← تحميل config.js، وحطه جوه فولدر website مكان الملف اللي فيه.
  2. افتح شات الكودينج، ارفع فولدر website، وابعتله الرسالة دي:
ارفع كل الملفات اللي في فولدر website ده على repo جديد في حسابي على GitHub اسمه perfume-shop، على الفرع main في الفولدر الرئيسي، وفعّل GitHub Pages من main / root، وابعتلي لينك الموقع لما يشتغل.
  1. لينك الموقع ده بيتبعت للعملاء. وحطه في تبويب الموقع ← رابط الموقع في البرنامج.
  2. صفحة المتابعة: نفس اللينك وفي آخره /admin.html. افتحها على موبايلك وادخل بالحساب الرئيسي، وبعدين من قايمة المتصفح اختار Add to Home screen، فهتبقى أيقونة زي الأبلكيشن.
  3. لو عايز حد تاني يتابع من غير ما يعدّل حاجة: الفروع والحسابات ← حساب متابعة.

توزيع طلبات الموقع

من تبويب الموقع: كل طلب بيروح لفرع واحد بس. تقدر تخليه حسب منطقة العميل، أو يتوزع بالتساوي على فروع تختارها، أو يروح لفرع واحد، أو توزعه انت بإيدك. الفرع اللي بيسلّم الطلب بيتسجل عنده بيعة والأزايز بتتخصم من مخزونه.
